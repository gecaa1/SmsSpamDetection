# Sposób uruchomienia (przykład)

Wymagania:
- `Python 3.13+`
- `virtualenv`/`venv` lub `uv`

Zależności:
- `numpy`
- `sympy`

Instalacja i uruchomienie:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 src/main.py --help
```

Parametry programu:
- `--input` ścieżka do pliku wejściowego
- `--help` wyświetla pomoc

Jeżeli projekt wymaga dodatkowych danych wejściowych, proszę je opisać
oraz dodać przykład uruchomienia z konkretnymi parametrami.
